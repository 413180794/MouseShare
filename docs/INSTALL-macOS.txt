MouseShare 0.7.5 — macOS 13+（Apple Silicon / Intel 请下载对应架构）

1. 打开 DMG，把 MouseShare 拖到 Applications（应用程序）。
2. 从应用程序启动 MouseShare。本预览版使用本机签名，尚无 Apple 开发者公证。
   如果 macOS 拦截，先尝试打开，再到「系统设置 → 隐私与安全性」点击「仍要打开」。
   请核对 GitHub 下载来源和 SHA-256；无需关闭系统安全功能。
3. 首次启动缺少权限时会打开向导；也可点击首页「设置键鼠权限」或侧栏「系统权限」。
   分别点击「开启辅助功能」「开启输入监控」，按系统提示在对应设置页面启用 MouseShare。
   列表没有应用时点「＋」，选择「应用程序」中的 MouseShare.app；验证请使用 Mac 登录密码或 Touch ID。
   返回向导后自动检查，也可点击「重新检查」。若系统要求退出并重新打开，请按提示操作。
   系统询问本地网络访问时选择允许。
4. 如果开启了 macOS 防火墙，请允许 MouseShare 接收入站连接。
5. 与 Windows 连接同一局域网。在列表里选择对方，两端核对相同的六位配对码并确认。
6. 在两端的「共享设置」中分别设置对方方向并保存。例如 Mac 位于 Windows 右侧：Windows 选右侧，Mac 选左侧。
7. 鼠标移到相接边缘立即跨屏，键盘自动跟随。沿原路移回即可返回。
8. Control+Option+F12 切换手动游戏模式；Control+Option+Esc 随时收回键鼠。
   部分键盘需同时按 Fn。操作目标电脑自己的实体键鼠也会收回控制。

游戏模式期间双向共享暂停。Windows 自动检测游戏进程和全屏窗口；Mac 使用手动游戏模式。
关闭窗口后驻留菜单栏，从菜单选择退出。登录启动需在拖入应用程序后主动开启。

数据：~/Library/Application Support/MouseShare
卸载：先在应用内关闭登录启动，再退出，把应用移到废纸篓。
完全删除还可移除上述数据目录及 ~/Library/LaunchAgents/io.github.makesail.mouseshare.plist。
取消配对请在两台电脑上分别操作。

版本与校验：https://github.com/413180794/MouseShare/releases


界面支持中文与英文，可在「共享设置 → 本机偏好 → 界面语言」立即切换；首次跟随系统。

English quick start
1. Drag MouseShare into Applications and open it. This preview uses an ad hoc signature.
2. Use System permissions to enable Accessibility and Input Monitoring. Each button opens
   the matching System Settings page; grant access and follow any Quit & Reopen prompt.
3. Start MouseShare on both computers, compare the six-digit pairing codes, and approve both.
4. Arrange touching screens in Screen layout and apply. Move to a shared edge to switch.
5. Control+Option+Esc reclaims input; Control+Option+F12 toggles game mode (Fn may be needed).
6. Choose Preferences > Local preferences > Language for English or Simplified Chinese.
Read the full English guide: https://github.com/413180794/MouseShare/blob/main/README.en.md
