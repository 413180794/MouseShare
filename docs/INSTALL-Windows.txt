MouseShare 0.3.0 — Windows 10/11 x64

1. Run MouseShare-0.3.0-Windows-x64-Setup.exe. The installer includes all runtime dependencies.
2. Keep the recommended private-network firewall rules enabled. Set your trusted LAN to Private.
3. Install MouseShare on the Mac, connect both computers to the same LAN, and start both apps.
4. Select the other computer and click 配对并连接 (Pair and Connect). Compare the six-digit code on BOTH computers.
5. Open 共享设置 (Sharing Settings) and set the other computer's position on EACH app. Example: Mac is to the Windows computer's right;
   on Windows select Right, and on Mac select Left. Save settings.
6. Move the mouse to the selected screen edge for 180 ms to switch. The keyboard follows.
7. Ctrl+Alt+F12 toggles game mode. Ctrl+Alt+Esc immediately returns control.
8. Enable login startup in the app settings after installing. Closing the window keeps the tray app running.

The interface is in Chinese. This preview is unsigned; Windows SmartScreen may show an unknown-publisher
notice. Verify the download source and SHA-256 before using More info > Run anyway.
Never disable antivirus. Anti-cheat, UAC secure desktop and privileged apps can block input injection.
Keep game mode enabled when playing games. Fullscreen detection also matches fullscreen video.

Portable ZIP: extract the entire folder, then run MouseShare.exe. Allow TCP 24872 and UDP 24871
on your private LAN if discovery is blocked. Administrator rights are only used for installer firewall rules.

Data: %LOCALAPPDATA%\MouseShare. Uninstall keeps settings and identity for reinstalling.
To remove trust permanently, cancel pairing in both apps, then remove this data directory.
