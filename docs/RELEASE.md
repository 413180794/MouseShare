MouseShare v0.3.0：加入剪贴板与文件共享。

- 文字、HTML 富文本、截图／图片双向同步；独立开关、来源标记防回传、后台检测，连接前的剪贴板保留在本机。
- 文件／文件夹复制和拖放传输：软件投递区、可选屏幕边缘投递口、文件选择、复制文件发送。接收后可复制粘贴或拖进 Finder／资源管理器。
- 接收确认、可选自动接收、进度／速度／预计时间、取消、重新发送、独立批次目录、SHA-256 校验及本机最近记录。
- 独立加密数据通道复用原 TCP 端口，保持键鼠通道独立；仅允许已认证并保持连接的配对设备传输。
- 游戏模式、暂停、锁屏和断线停止共享；失败清理临时文件，保留源文件与已存在的同名文件。

两端均升级至 v0.3.0 才能共享内容；与旧版连接保留键鼠功能。文件拖放采用投递口交接；连续跨屏拖动、多显示器与断点续传列入后续计划。详细使用方式见 [文件与剪贴板](https://github.com/413180794/MouseShare/blob/main/docs/SHARING.md)。

保留 v0.2.4 的 Mac 双光标修复：

- Mac 交出键鼠控制时，本机光标停留在交接位置；移动继续作用于 Windows。
- 共享期间每次移动都保持原交接位置，本机以零增量事件更新系统光标，并由不抢焦点的透明窗口接住移动。Windows 接收原始物理增量；Mac 返回、退出或故障时关闭窗口、恢复光标。
- 返回 Mac、紧急收回、游戏模式、暂停、断线、握手超时与退出时恢复本机鼠标。
- Mac 输入监听被禁用、回调异常及队列溢出时也会恢复本机控制。冻结调用失败会中止共享。
- 保留 v0.2.1 的新版界面与图标，以及 v0.1.2 的边缘进入和返回位置修复。

支持 Windows 与 macOS 的局域网键鼠共享：

- 自动发现、两端核对配对码、TLS 加密、配对后自动重连。
- 四个方向的边缘切换、键盘跟随、点击／拖动／滚动、物理按键传输。
- 手动游戏模式；Windows 前台全屏或指定游戏进程自动锁定。
- Ctrl+Alt+F12 切换游戏模式，Ctrl+Alt+Esc 收回键鼠。
- 托盘常驻、主动开启登录启动、断线释放远端按键。

下载 Windows 的 `Setup.exe` 与 Mac 对应架构的 `.dmg`。
Apple Silicon 用 arm64，Intel 用 x86_64。Windows 还提供解压即用的 portable.zip。
安装包内含运行依赖，无需安装 Python。

首次在两台电脑上核对六位配对码，并分别设置对方位于本机的方向。
Mac 须开启辅助功能和输入监控权限；系统询问本地网络时选择允许。
Windows 安装时可启用专用网络的局域网防火墙规则。

v0.1.0 已在实体 Windows ↔ Mac 双机完成安装、发现、配对、重连与基础跨屏试用；v0.1.2 已由用户在实体 Windows → Mac → Windows 往返中确认：源端光标保持边缘，返回位置正确。v0.2.4 已由用户使用实体 Mac 鼠标确认：进入 Windows 后只有 Windows 光标移动，返回 Mac 正常。其余方向、DPI 组合和具体游戏仍需继续验收。自动测试覆盖真实本机 TLS 双端通信、
配对安全、重连和输入状态机；CI 在 Windows 和两种 Mac 架构构建并检查打包后的程序。
输入共享当前以主显示器为边界；接收端输入法负责文字转换。
跨电脑拖放文件、剪贴板、登录／锁屏界面及提权安全桌面不在当前版本范围。

程序尚无商业代码签名和 Apple 公证，系统可能提示未知发布者。
请从此仓库下载，核对 `SHA256SUMS.txt`，按 README 的系统放行步骤安装。
游戏反作弊可能限制输入钩子或合成输入；请在玩游戏时保持游戏模式开启。
