MouseShare v0.2.2：修复 Mac 鼠标进入 Windows 后，两台电脑光标同时移动的问题。

- Mac 交出键鼠控制时，本机光标停留在交接位置；移动继续作用于 Windows。
- 返回 Mac、紧急收回、游戏模式、暂停、断线、握手超时与退出时恢复本机鼠标。
- Mac 输入监听被禁用、回调异常及队列溢出时也会恢复本机控制。冻结调用失败会中止共享。
- 保留 v0.2.1 的新版界面与图标，以及 v0.1.2 的边缘进入和返回位置修复。

支持 Windows 与 macOS 的局域网键鼠共享：

- 自动发现、两端核对配对码、TLS 加密、配对后自动重连。
- 四个方向的边缘切换、键盘跟随、点击／拖动／滚动、物理按键传输。
- 手动游戏模式；Windows 前台全屏或指定游戏进程自动锁定。
- Ctrl+Alt+F12 切换游戏模式，Ctrl+Alt+Esc 收回键鼠。
- 托盘常驻、主动开启登录启动、断线释放远端按键。

下载 Windows 的 `Setup.exe` 与 Mac 对应架构的 `.dmg`。
Apple Silicon 用 arm64，Intel 用 x86_64。Windows 还提供解压即用的 portable.zip。
安装包内含运行依赖，无需安装 Python。

首次在两台电脑上核对六位配对码，并分别设置对方位于本机的方向。
Mac 须开启辅助功能和输入监控权限；系统询问本地网络时选择允许。
Windows 安装时可启用专用网络的局域网防火墙规则。

v0.1.0 已在实体 Windows ↔ Mac 双机完成安装、发现、配对、重连与基础跨屏试用；v0.1.2 已由用户在实体 Windows → Mac → Windows 往返中确认：源端光标保持边缘，返回位置正确。其余方向、DPI 组合和具体游戏仍需继续验收。自动测试覆盖真实本机 TLS 双端通信、
配对安全、重连和输入状态机；CI 在 Windows 和两种 Mac 架构构建并检查打包后的程序。
输入共享当前以主显示器为边界；接收端输入法负责文字转换。
跨电脑拖放文件、剪贴板、登录／锁屏界面及提权安全桌面不在当前版本范围。
