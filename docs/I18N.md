# App localization

`mouseshare/i18n.py` owns locale selection and app-authored `Message` values. English translations are in `mouseshare/locales/en.json`; the source language is Simplified Chinese. Use `tr('source', name=value)` with named placeholders. Keep device names, filenames, process basenames, protocol keys and clipboard contents as literal data. Translate complete messages to allow English word order.

Presentation modules import the small Qt wrappers in `i18n_widgets.py`. They retain message sources and parameters for text, tooltips, accessibility labels, combo items and form labels. Switching languages updates those properties in place. It must not rebuild the main window, restart input hooks, reconnect sessions, cancel transfers, overwrite layout drafts or save unrelated preference fields. Custom painting resolves messages while drawing. New UI controls need a retained binding or an explicit repaint path.

Stored preferences use `language = system | zh_CN | en`. Chinese system locales resolve to Simplified Chinese; other locales resolve to English. Unknown preferences fall back to the system language. The packaged dependency smoke test checks both catalogs. macOS `InfoPlist.strings` follows the OS language separately from the in-app preference.

Run `python -m pytest tests/test_i18n.py -q` for catalog/placeholder coverage, English pages, minimum-width controls, all platform permission guides, literal user data and live-switch state preservation. `scripts/preview.py --language en` renders isolated sample screens without input hooks or network. The English README uses those sample screenshots.
