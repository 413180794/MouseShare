当前自动化验证与实机验收分别记录。代码测试通过及安装包构建成功，均不能代替下列实际桌面交互检查。

- Mac 型号／CPU／macOS：待填

## 安装和授权

- [ ] Windows 全新普通用户环境安装，安装程序提权添加专用网络规则，应用随后以普通用户启动。
- [ ] Windows 完整解压便携 ZIP 可以启动。
- [ ] Mac DMG 拖入应用程序，完成 Gatekeeper 放行、辅助功能、输入监控和本地网络授权。
- [ ] 两台电脑自动出现在列表。关闭组播时验证手动 IPv4 连接。
- [ ] 两端配对码相同；拒绝后没有输入控制，确认后成功连接。
- [ ] 重启两端应用，配对设备自动重连；取消配对后重新要求确认。

## 键鼠

- [ ] Windows 鼠标从配置边缘进入 Mac，Mac 鼠标从配置边缘进入 Windows。
- [ ] 两个方向分别验证字母、中文输入法、Shift、Ctrl／Command、复制粘贴、F 键、方向键和数字小键盘。
- [ ] 验证左／右／中键、双击、拖动、水平／垂直滚轮、前进／后退侧键。
- [ ] 主屏四种边缘方向及不同分辨率／DPI 缩放正确。
- [ ] 四个方向分别快速甩到边缘，在两端分辨率／缩放不同、较高鼠标回报率及延迟增加时，目标从对应边缘入场；首次入场没有跳到屏幕中部。验证握手期间的累计移动，并保留回归测试。
- [ ] 分别使用 Windows 和 Mac 的实体鼠标发起共享，源端光标始终留在交接边缘；快速移动、较高回报率和反复往返时均保持稳定。Windows 使用 Raw Input；Mac 使用 HID 事件拦截和 Quartz 光标关联断开，相对位移与源端光标位置分别处理。
- [ ] Mac → Windows 必须在 MouseShare 位于前台、退到后台或托盘常驻时分别验证：Windows 光标移动，Mac 光标静止，本地应用收不到移动／点击／键盘。只验证转发的 dx/dy 或 Windows → Mac，均不足以确认此项。
- [ ] Mac 正在控制 Windows 时，分别验证原路返回、Ctrl+Alt+Esc、游戏模式、暂停、断线、握手超时、监听被禁用及退出，Mac 实体鼠标立即恢复。冻结调用失败应中止切换，禁止带着源端仍可移动的状态继续共享。
- [ ] 四个方向在目标不同高度／横向位置返回，源端恢复至对应边缘和比例位置；断线、紧急收回和切换超时时回到原交接位置。
- [ ] 源端本地应用不会同时收到转发中的点击或按键。
- [ ] 从目标原路返回，源端键鼠恢复；目标本机实体输入会收回控制。

## 游戏和故障

- [ ] 按 Ctrl+Alt+F12 打开手动游戏模式，原游戏能正常接收本机键鼠，移动到任何边缘保持本机控制。
- [ ] 启动实际游戏，确认进程检测触发；使用无边框／独占全屏分别检查。
- [ ] Alt+Tab 离开游戏后自动状态恢复；手动游戏模式保持到主动关闭。
- [ ] 关闭全屏检测后，全屏视频保持可共享；游戏进程检测继续生效。
- [ ] 正在远端按住 Shift／Ctrl 或鼠标按钮时拔网线，约 3.5 秒后两端释放状态。
- [ ] 正在控制远端时按 Ctrl+Alt+Esc，立即收回且远端无卡键。
- [ ] 锁屏／睡眠／唤醒后按预期停止，重新登录后重连。
- [ ] 退出应用、重复启动、登录启动和卸载行为正确。
