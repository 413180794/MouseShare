# 桌面界面约定

MouseShare 是日常常驻的双机工具。首页优先展示连接、设备位置、当前控制状态，以及游戏模式和收回操作；跨屏参数放在「共享设置」，自动游戏规则放在「游戏模式」。手动 IP 连接默认折叠。

界面使用浅色背景、白色内容区和青绿色强调。标题、正文、辅助说明和状态具有固定层次；连接、暂停和待授权除颜色外同时使用文字区分。图示中的设备名称应截断或换行，完整名称可在设备列表查看。四种方向的图示均应完整显示。

设置页的保存入口固定在底部，成功和校验错误在当前页面可见。940×720 最小窗口下检查导航、保存入口和滚动区域。保留平台原生键盘导航、焦点和可访问名称。系统深色模式下控件仍使用完整浅色调色板。

应用、窗口、安装包图标均来自 `mouseshare/branding.py`；菜单栏使用专用单色模板。修改图标时同时检查 16/32/128/512 像素，避免运行图标与安装图标分叉。

每次布局调整，运行 `python scripts/preview.py` 渲染真实 Qt 控件，检查连接、离线、权限、游戏锁定和四种屏幕方向。截图仅使用隔离的演示数据。实际安装后再用原生界面检查导航、状态更新、游戏开关和自动重连。保留配对数据；跨屏修复继续按 `ACCEPTANCE.md` 验收。

附近设备使用可选择的原生按钮卡片，保持键盘导航及完整的可访问名称；发现和状态刷新原位更新已有卡片。Qt 6.10.3 的 Cocoa 表格 `accessibilitySelectedChildren` 在原生检查时出现过悬空对象崩溃，禁止恢复为该表格实现。Mac 原生验收必须在设备已选中时，跨越多次发现刷新读取辅助功能树并切换页面；离屏渲染无法覆盖 Cocoa 可访问性桥接。

「文件与剪贴板」独立成页，接收请求与进度位于偏好设置上方。文件动作按钮在进度更新时保留实例，避免按下期间被替换；主屏边缘投递口由用户主动开启，在游戏／暂停／安全桌面或失效连接时隐藏。文件拖放以复制动作交接，不改变现有键鼠按住保护和源端光标逻辑。

文件投递提示只占实际目标边缘的一小块区域，在拖入点附近出现；禁止整屏遮罩、整屏变暗或整屏模糊。四方向／负坐标／常见屏幕尺寸下均需验证窗口位于屏幕内部、紧贴正确边缘、覆盖拖入点且面积小于屏幕 15%。接触屏幕的边缘保持可命中，内侧转角圆润。设备名与文件名保留原文，验证中英文。

动态效果仅改变局部光晕和文件图案：约 5.6 秒一轮、图案漂移不超过 1.8 像素。投递窗口、设备文字与关闭入口保持固定；隐藏后停止动画计时器，Mac／Windows 系统减少动态效果时使用静态提示。原生模糊和交互窗口使用同一范围，空闲桌面保持原样。手势内绑定初始认证目标，离开／取消／断线／暂停后收起。
