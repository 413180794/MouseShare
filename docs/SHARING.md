# 文件与剪贴板

两端升级至 v0.5.0，配对连接后使用侧栏「文件与剪贴板」。与旧版连接时保留键鼠共享，内容共享需要双方升级。

## 复制文字、网页内容和截图

连接后新复制的文字、HTML 富文本和图片自动同步。在另一台电脑按对应系统的粘贴快捷键即可。首次连接和从游戏模式恢复时保留当前剪贴板，重新复制要同步的内容。Windows 使用 Ctrl+C／Ctrl+V，Mac 使用 ⌘C／⌘V；Windows 键盘上的 Win 键对应 Mac ⌘，也可在「共享设置」开启接收时交换 Ctrl 与 ⌘。

剪贴板总开关控制文字／富文本共享，图片和复制文件各有附加选项。文字与富文本合计最多 2 MiB，整份剪贴板最多 8 MiB，图片最多 1600 万像素。更大的图片可保存后按文件发送。已收到的内容带来源标记，避免来回同步。密码管理器标记为 concealed / transient / password 的内容会跳过；普通文本会按共享开关处理。

## 文件复制和拖放

- 在 Finder、资源管理器或 X11 文件管理器复制文件／文件夹，只共享文件名和本次复制标识。移动到目标电脑的文件夹，按 **Ctrl+Alt+Shift+V**（Mac：Control+Option+Shift+V），文件按需取回，校验完成后直接粘贴。**Ctrl+Alt+Shift+C** 可主动执行源端系统复制并发布；也支持源端普通 Ctrl+C／⌘C。
- 默认支持目标端系统 Ctrl+V／⌘V，可在页面关闭。接管条件是本机收到新文件信息且此后剪贴板未改变。复制普通内容会恢复原有系统粘贴方式；专用粘贴键可显式选取远端文件。Linux 快捷键冲突时使用页面按钮或先调整桌面快捷键并重启。
- 自动接收仅对应本机发起的随机单次请求，绑定源设备和复制标识。传输后检查原窗口、输入活动、剪贴板及控制会话；保持原状态才执行系统粘贴。发生变化时保留已接收文件，可在记录中「复制文件」后手动粘贴。剪切文件始终按副本处理。
- v0.3/v0.4 旧版连接保留逐批确认方式。多台设备下，文字／图片跟随当前控制或选中的电脑；文件信息发布给已连接的新版本配对电脑，显式发送可以选择目标。
- 将文件拖进软件内投递区，或开启「拖文件到屏幕边缘时，展开全屏毛玻璃投递层」。拖文件到布局中已连接的相邻屏幕边缘后，浮层会展示目标电脑、文件数量和取消提示；松手提交后迅速收起，文件在后台传输。平时隐藏，普通鼠标移动和文字拖动不会展开。文件在被远端键鼠控制的电脑上发起拖动时，也支持此方式。对方接收完成后，可从记录的「拖出文件」按钮拖入 Finder、资源管理器或支持文件的应用。
- 「选择文件」「选择文件夹」「发送已复制的文件」提供等价入口。拖放始终复制，源文件保留。源文件名需要两种系统均支持；符号链接、特殊文件、大小写冲突及 Windows 保留名称需先整理。

跨电脑拖放采用全屏投递层交接：源端放下文件 → 对方接收 → 从接收记录拖到目标位置。原 Finder／资源管理器的拖动会话在投递层结束。Mac 使用 NSVisualEffectView，Windows 11 使用 Desktop Acrylic，兼容桌面按合成器能力显示模糊或深色半透明背景。尊重系统减少透明度设置；不读取或保存桌面截图，不增加屏幕录制权限。「预览投递效果」可查看 3 秒演示，Esc 或右上角关闭。按住文件直接穿过屏幕边缘、在另一台电脑任意窗口松开的连续拖动继续列为后续原生集成工作。

## 接收、进度和记录

显式发送默认逐批确认，可主动开启已配对电脑自动接收。本机快捷键发起的有效粘贴请求自动接收对应批次。默认接收目录是 `下载/MouseShare`，可在页面更改。每批保存到独立时间戳文件夹，现有同名文件保留；校验完成后才能打开所在目录、复制或拖出。

单批最多 100 GiB、4096 个文件／文件夹、32 层目录；以流式方式传输，内存占用不随文件大小增长。显示已传字节、平均速度和预计剩余时间，可取消；失败可重新发送。取消、断线或校验失败会清除临时文件。当前重试从头开始。接收端需要总量之外至少 10 MiB 空间。

最近 20 条完成／失败记录保存在本机 `transfers.json`，只包含任务状态、文件名与路径等元数据。清空记录保留已接收文件。剪贴板内容和文件内容不会写入日志或传输记录。

## 游戏、暂停和连接

游戏模式、暂停共享、锁屏和断线时停止内容共享并取消进行中的文件任务。退出保护后重新复制或发送。接收和传输使用独立 TLS 连接，复用 TCP 24872，无需新增防火墙端口；要求同一设备已有认证并保持连接。文件逐项校验 SHA-256，拒绝路径越界和跨平台文件名冲突。

## 后续功能顺序

1. 单台电脑的多显示器独立布局：当前每台电脑使用主显示器参与全局排列。
2. 大文件断点续传：保存可验证的分块进度，原文件改变时重新发送。
3. 文件管理器原生连续拖动：分别对接 Windows OLE 和 macOS 拖动会话，保留当前可用的投递口方式。
4. 连接诊断与延迟显示：把网络、系统权限、游戏保护的原因集中展示。
